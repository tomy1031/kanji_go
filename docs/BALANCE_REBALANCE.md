# Rebalance pass (practice count, enemy stats/EXP, counter-chain, UI)

This pass fixes concrete balance and UX problems found by auditing the real
data model (`monster_data.csv` + `stage_data.csv` + `exp_table.csv`).

Re-run the audit anytime:

```bash
node scripts/balance_audit.mjs     # per-stage difficulty + boss counter-chain
node scripts/retune_balance.mjs    # regenerates enemy stats/EXP + exp_table (idempotent rules)
```

## Problems found (before)

- **34 of 60 stages gave 0 EXP.** Many stage enemies (incl. several bosses)
  were placeholder rows with `expReward=0`, so `isEnemy` was false and beating
  them granted nothing. The player level (~12) fell far behind enemy levels
  (up to 50) → late game was unwinnable.
- **34 enemies had placeholder stats `100/30`** (incl. bosses), so difficulty
  jumped and dipped unpredictably ("sudden spikes / weak bosses").
- **6 Light/Dark bosses had no counter** meta-monster available before them —
  the core "beat a stage → get the counter for the next boss" loop was broken.
- **EXP table only reached level 20** while enemies scale to level 50.
- The writing-practice mastery count was **20**.

## Changes

- **`monster_data.csv`**: every monster used as a stage enemy now has authored
  stats + non-zero EXP, tiered by version (N5/N4/N3) and role (normal/boss).
  Real, already-tuned enemies are untouched. (Generated by
  `scripts/retune_balance.mjs`.)
- **`exp_table.csv`**: extended to level 55 using the existing curve
  `total = 50 * L * (L-1)`, so the player can keep pace with enemy levels.
- **`stage_data.csv`**: the stage before each Light/Dark boss now rewards the
  correct counter element (Dark before a Light boss, Light before a Dark boss),
  closing all 6 chain gaps. All 15 bosses now have a counter available.
- **Practice count → 10**: new `src/lib/constants.ts` `PRACTICE_MASTERY_COUNT`,
  used by `userStore` and `PracticeMode` (was hard-coded 20 in many places).
- **BattleScene**: initialize enemy HP from the stage's enemy level (matches
  the HP-bar max) so the bar starts full.
- **UI**: `h-screen` → `h-dvh` across screens (fixes the mobile `100vh` cutoff),
  and hero screens (Title / Menu / Starter) are scrollable on short screens.

## Result (after, from `balance_audit.mjs`)

- Stages giving 0 EXP: **0** (was 34)
- Placeholder `100/30` enemies: **0** (was 34)
- Player level now tracks enemy level reasonably across all 60 stages
- Boss counter-chain: **15/15 bosses have a counter available**

## Notes / possible follow-ups

- A few *real* (non-placeholder) monsters used as bosses are still a little
  under-statted vs their world's normal enemies (e.g. some N4 wolf/golem
  bosses). They are within range but could be buffed for more "boss feel".
- The PWA precache is very large (~200MB: all monster art + 3.7k stroke files).
  Consider runtime-caching the heavy art instead of precaching it.
