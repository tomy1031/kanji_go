# UI レビュー：問題点と改善提案

Kanji GO の各画面を調査して見つかったUIの問題点と、改善提案をまとめます。
優先度は 🔴 高（体験を損なう／操作不能）/ 🟡 中 / 🟢 低（磨き込み）。

---

## このPRで対応済みの修正

### 🔴 スクロールできない（最重要）
**原因:** ルート（`App.tsx`）と各画面が `h-screen` + `overflow-hidden` を多用していたため、
コンテンツがビューポートより高いと**はみ出した部分に一切アクセスできない**状態でした。
さらに `h-screen`（=`100vh`）はモバイルブラウザのアドレスバー分を含むため、
画面下部（「PRESS START」ボタンや書き取りキャンバス）が隠れることがありました。

**対応:**
- ルートを `min-h-dvh` + `overflow-x-hidden` に変更し、ページ全体が縦に伸びてスクロールできるように。
- コンテンツ画面（メニュー / タイトル / スターター選択 / パートナー状態）を `min-h-dvh` 化し、
  中央寄せのまま縦長コンテンツでもスクロール可能に。
- 固定ビューポート系（バトル / マップ / 練習 / カートリッジ選択）は `h-screen` → `h-dvh` に変更し、
  モバイルの `100vh` ずれを解消。

### 🟡 バトルの「Exit Battle」ボタンが敵HUDと重なる
`Exit Battle`（右上 `top-4 right-4`）と敵のステータスHUD（同じく右上）が重なっていました。
→ Exit ボタンを**右下**に移動。

## 未対応の問題点と改善提案（要ご判断）

### 🔴 ワールドマップがレスポンシブでない
- ステージノードを `getPosition()` で `%` の絶対座標に固定配置（3列ジグザグ）。
  幅80pxの円を `top/left %` で置くため、**狭い画面ではノードやラベルが重なり・見切れ**ます。
- ステージ数を増やすと上方向（`y = 80 - floor(i/3)*20`）に伸び、画面外に出ます。
- **提案:** CSS Grid もしくは縦スクロール可能な「すごろく」レイアウトに変更。
  ノードを相対配置にし、経路の SVG も grid に追従させる。スマホ縦持ち前提で1〜2列に。

### 🔴 タッチ操作で選択フィードバックが出ない
- スターター選択 / カートリッジ選択 / パートナー状態が `onMouseEnter`/`hover` 前提のハイライト。
  **タッチデバイスでは hover が無い**ため、どれが選択中か分からないまま確定してしまう。
- **提案:** 「タップで選択（ハイライト）→もう一度タップで確定」の2段階に統一。
  `focusedId` をタップで設定し、選択中カードに枠/拡大を付与（カートリッジ選択は既にこの方式なので踏襲）。

### 🟡 練習モードから実際に書き取り練習ができない
- `PracticeMode` は漢字一覧（図鑑）ビューで進捗（`n / 10`）を表示するだけで、
  **カードをタップしても書き取り練習が始まりません**。書き取りはバトル中のみ。
- 「練習をしてからステージに挑む」というコンセプト的に、ここで練習できないのは惜しい。
- **提案:** カードをタップ → `KanjiWriterCanvas`（quizモード）のモーダルを開き、
  正解するたび `masteryCount` を加算（`MASTERY_THRESHOLD=10` で習得）。
  バトルのSRS更新（`calculateNextReview`）も再利用可能。

### 🟡 バトル画面が小／低い画面で要素が重なる
- HUD（上部に3ブロックを `justify-between`）が狭い画面で**バトルメッセージと重なる**。
- モンスターは絶対配置中央、書き取りキャンバス（280px）は `absolute bottom-8`。
  低い画面ではモンスターとキャンバスが**重なる**。
- **提案:** 縦フレックスの3段レイアウト（上=HUD / 中=モンスター / 下=キャンバス）に再構成し、
  各段を `flex-shrink` 可能に。キャンバスサイズを画面高に応じて可変（例 `min(280px, 40vh)`）。

### 🟡 HPバーが常に満タン表示（マップHUD）
- `WorldMap` の HP バーが `w-full` 固定（常に100%）。実HPと無関係。
- **提案:** 実データ（または「最大HP」表示）に合わせる。あるいは経験値バーに置き換え。

### 🟢 不要・不整合なファイル/設定
- `src/App.css` は Vite テンプレートの残骸（`#root { max-width:1280px; padding:2rem }` 等）。
  **どこからも import されていない**ため無害ですが、誤って読み込むとレイアウトが崩れます。削除推奨。
- `public/vite.svg` / `src/assets/react.svg` などテンプレ残骸。
- `index.html` の favicon が `vite.svg`、`<title>` が `kanji_go`。
  ブランド表記（`Kanji Go` 等）とアイコンを整えると体感品質が上がります。

### 🟢 アクセシビリティ / その他
- アイコンのみのボタン（戻る「←」等）に `aria-label` が無い。
- 画像 `alt` は概ねあるが、装飾画像は `alt=""` に。
- 配色コントラスト：`text-white/50` の著作権表記などは背景により読みづらい場合あり。
- 多くのテキストが英語。学習者向けに日本語/英語の併記やi18nを検討。
